# 移除新聞文章頁「相關地理位置」座標區塊

- **作者**：Claude（診斷會話）
- **日期**：2026-09-20
- **狀態**：Draft
- **對應使用者回報**：「7. 新聞卡拿掉座標功能」

## 1. 範圍確認（已與使用者確認過，不用再問）

使用者要拿掉的是新聞文章頁底部的「相關地理位置」區塊，也就是 `components/News/NewsMapCard.tsx`（顯示小地圖 + `{lat.toFixed(4)}°N, {lng.toFixed(4)}°E` 經緯度數字），**整個區塊全部移除**（地圖與經緯度數字都要拿掉），不是只拿掉數字、也不是新聞列表卡片上的距離顯示（那是 `components/News/NearbyWeatherBar.tsx` 的功能，不在本次範圍內，不要動）。

## 2. 待辦事項

1. 找出所有引用 `NewsMapCard` 的地方（預期在新聞文章頁面元件內），移除該區塊的渲染。
2. 若移除後 `NewsMapCard.tsx` 已無任何引用者，直接刪除該檔案（不要留下沒人用的死程式碼）。
3. 檢查是否有其他程式碼專門為了餵資料給 `NewsMapCard`（例如文章資料抓取時特地解析地點座標 `lat`/`lng`/`facilityId`/`approximate`），若這些資料只被 `NewsMapCard` 使用、拿掉後完全沒有其他用途，一併清除；若該座標資料還有其他用途（例如儲存在資料庫供其他功能用），則保留資料本身，只拿掉這個 UI 呈現。
4. 檢查是否有對應的測試（例如 `NewsMapCard` 相關的 snapshot/unit test）需要一併移除或更新。

## 3. 驗收標準

- 新聞文章頁面不再顯示「相關地理位置」區塊（地圖、經緯度數字皆不顯示）。
- `npm run build` 與 `npm test` 通過，沒有殘留對已刪除元件的引用（TypeScript 編譯不出現找不到模組的錯誤）。
- 不影響新聞列表卡片上既有的距離顯示功能（`NearbyWeatherBar` 等）。
